    ONNX Runtime 1.28.0 オフライン導入手順¶

    目的¶

    既存のPython環境やアプリケーション環境への影響を可能な限り避けながら、WindowsオフラインPCへONNX Runtime 1.28.0 CPU版を導入し、正常にimportできることを確認する。

    1. 前提¶

    使用Python：

    1
    Python 3.11.9 x64

    検証用構成：

    1
2
3
    C:\ort_test
├─ wheels
└─ venv

    既存環境への影響を避けるため、ONNX Runtimeは既存Python環境へ直接インストールせず、新規venvへインストールする。

    2. オンラインPC：wheel取得¶

    PowerShellで保存先を作成する。

    1
    New-Item -ItemType Directory -Force C:\ort_test\wheels

    ONNX Runtime 1.28.0と必要な依存wheelを取得する。

    1
    python -m pip download onnxruntime==1.28.0 --only-binary=:all: -d C:\ort_test\wheels

    取得内容を確認する。

    1
    Get-ChildItem C:\ort_test\wheels

    以下の5ファイルを取得。

    1
2
3
4
5
    flatbuffers-25.12.19-py2.py3-none-any.whl
numpy-2.4.6-cp311-cp311-win_amd64.whl
onnxruntime-1.28.0-cp311-cp311-win_amd64.whl
packaging-26.3-py3-none-any.whl
protobuf-7.35.1-cp310-abi3-win_amd64.whl

    C:\ort_test\wheels フォルダをオフラインPCへコピーする。

    コピー先：

    1
    C:\ort_test\wheels

    3. オフラインPC：検証用venv作成¶

    1. Python 3.11.9の実行ファイルを使用してvenvを作成する場合。

    Pythonの場所が通常のPATH上にある場合：

    1
    python -m venv C:\ort_test\venv

    Pythonを専用フォルダへ入れている場合は、Pythonをフルパス指定する。

    例：

    1
    C:\ort_test\Python3119\python.exe -m venv C:\ort_test\venv

    作成されたPythonを確認する。

    1
    C:\ort_test\venv\Scripts\python.exe -V

    期待結果：

    1
    Python 3.11.9

    実際に使用されるPythonを確認する。

    1
    C:\ort_test\venv\Scripts\python.exe -c "import sys; print(sys.executable)"

    期待結果：

    1
    C:\ort_test\venv\Scripts\python.exe

    venvをActivateする必要はない。

    以後は常に、

    1
    C:\ort_test\venv\Scripts\python.exe

    をフルパス指定する。

    1. 既存Pythonから検証用venvを作成する場合。 既存Pythonが3.11.9の確認 
      1
2
      python -V
where.exe python

    検証用venvを作成 

    1
    python -m venv C:\ort_test\venv

    有効化してinstall。 

    1
2
    C:\ort_test\venv\Scripts\Activate.ps1
python -m pip install --no-index --find-links=C:\ort_test\wheels onnxruntime==1.28.0

    確認 

    1
    C:\ort_test\venv\Scripts\python.exe -c "import onnxruntime as ort; print(ort.__version__)"

    4. ONNX Runtime 1.28.0をオフラインインストール¶

    以下を実行する。

    1
    C:\ort_test\venv\Scripts\python.exe -m pip install --no-index --find-links=C:\ort_test\wheels onnxruntime==1.28.0

    --no-index によりPyPI等のオンラインリポジトリを使用しない。

    --find-links=C:\ort_test\wheels により、指定フォルダ内のwheelだけを使用する。

    5. インストール確認¶

    1
    C:\ort_test\venv\Scripts\python.exe -m pip list

    ONNX Runtimeのバージョンを確認する。

    1
    C:\ort_test\venv\Scripts\python.exe -c "import onnxruntime as ort; print(ort.__version__)"

    正常な場合：

    1
    1.28.0

    と表示される。

    6. DLLエラーが発生した場合の記録¶

    以下のエラーが発生した場合：

    1
2
    ImportError: DLL load failed while importing onnxruntime_pybind11_state:
A dynamic link library (DLL) initialization routine failed.

    まずVisual C++ Runtime DLLのバージョンを記録する。

    1
    (Get-Item "C:\Windows\System32\MSVCP140.dll").VersionInfo.FileVersion

    1
    (Get-Item "C:\Windows\System32\VCRUNTIME140.dll").VersionInfo.FileVersion

    1
    (Get-Item "C:\Windows\System32\VCRUNTIME140_1.dll").VersionInfo.FileVersion

    さらにイベントビューアーで以下を確認する。

    1
2
    Windowsログ
 → アプリケーション

    確認項目：

    1
2
3
    障害が発生したアプリケーション
障害が発生したモジュール
例外コード

    7. VC++ Runtime原因切り分け¶

    最初からVC++ Runtimeを更新しない。

    まず現在のPC環境のまま、

    1
    C:\ort_test\venv\Scripts\python.exe -c "import onnxruntime as ort; print(ort.__version__)"

    を実行する。

    エラーが再現した場合のみ、Visual C++ Redistributable x64を更新して再起動する。

    その後、同じvenv・同じwheelのまま再度実行する。

    1
    C:\ort_test\venv\Scripts\python.exe -c "import onnxruntime as ort; print(ort.__version__)"

    結果：

    1
2
    更新前：NG
更新後：OK

    となれば、Visual C++ Runtime環境が原因だった可能性が非常に高い。

    8. requirements.txtを使用した本来の環境との比較¶

    ONNX Runtime単体で正常動作を確認した後に、別のvenvを作成する。

    1
    python -m venv C:\ort_test\venv_full

    元アプリケーションのrequirements.txt用wheelをオンラインPCで取得する。

    1
    python -m pip download -r requirements.txt -d C:\ort_test\wheels_full

    オフラインPCへコピーした後、

    1
    C:\ort_test\venv_full\Scripts\python.exe -m pip install --no-index --find-links=C:\ort_test\wheels_full -r requirements.txt

    でインストールする。

    その後、

    1
    C:\ort_test\venv_full\Scripts\python.exe -c "import onnxruntime as ort; print(ort.__version__)"

    を実行する。

    結果を比較する。

    1
2
    ONNX Runtimeだけのvenv       → OK
requirements全体のvenv       → NG

    となった場合、requirementsに含まれる別パッケージまたはパッケージバージョンとの競合を疑う。
