    Camera Settings¶

    Marathon系では、使いたいAppletをあらかじめボードへFlashして「利用可能なApplet」にしておき、その後、撮像ソフト側で使用するAppletを選択する、という構成にできます。Basler公式でも、marathonではAppletはボードへFlashされた時点で利用可能になり、GenTLのInterfaceAppletノードから現在ロードするAppletを切り替えられるとされています。

    例えば、

  └─ Acq_SingleBaseLineGray

    GenTL経由では、Basler Producerが公開するInterfaceノードに

    HAPを「作る」場合¶

    これは別段階です。

    標準Appletでは機能が足りず、自分でFPGA処理を作りたい場合は VisualApplets という専用ツールを使います。そこで画像取得・処理回路をGUIで構成し、Hardware Appletとして.hapを生成します。生成した.hapはフレームグラバへロードできます。VisualAppletsの資料でも、.hapをLoadしてフレームグラバへ入れる手順が説明されています。

    ただし「確認用」であれば、HAP自作は不要です。

    まずは、 

    1
2
    標準Applet
Acq_SingleBaseAreaBayer
    を使えば十分です。

    1
2
3

    "SiliconSoftware",
    "camera_type",
    ...)
    の結果で、ccf または 等が明示されている場合だけ CameraType にパスを渡す設計にした方が安全

    static Dictionary<string, string> ParseInfoBoard(string text)
{
    var result = new Dictionary<string, string>(
        StringComparer.OrdinalIgnoreCase);

    string[] parts = text.Split('|');

    foreach (string rawPart in parts)
    {
        string part = rawPart.Trim();

        if (string.IsNullOrEmpty(part))
            continue;

        int separator = part.IndexOf(':');

        if (separator <= 0)
            continue;

        string key = part.Substring(0, separator).Trim();
        string value = part.Substring(separator + 1).Trim();

        result[key] = value;
    }

    return result;
}

    HOperatorSet.InfoFramegrabber(
    "GenICamTL",
    "info_boards",
    out HTuple boards);

for (int i = 0; i < boards.Length; i++)
{
    string text = boards[i].S;

    var info = ParseInfoBoard(text);

    info.TryGetValue("device", out string device);
    info.TryGetValue("producer", out string producer);
    info.TryGetValue("tl_type", out string tlType);
    info.TryGetValue("vendor", out string vendor);
    info.TryGetValue("model", out string model);

    Console.WriteLine($"Device   = {device}");
    Console.WriteLine($"TL Type  = {tlType}");
    Console.WriteLine($"Producer = {producer}");
    Console.WriteLine($"Vendor   = {vendor}");
    Console.WriteLine($"Model    = {model}");
}
