    ① プラットフォームを x64 に固定（最重要）

    Sick.GenIStreamDotNet は内部で x64 ネイティブ DLL を P/Invoke します。 → 新規プロジェクトが Any CPU + Prefer 32-bit = ON だと 32bitプロセスで起動し、BadImageFormatException になります。

    プロジェクトのプロパティ → Build

    Platform target = x64 を選択

    Prefer 32-bit のチェックを外す

    ソリューション構成マネージャでも Active solution platform = x64 に揃える

    もし x86 構成が残っていたらビルド対象から外す

    サンプルプロジェクトの構成（x64）と同じにしてください。

    ② .NET の種類を合わせる（.NET Framework を使う）

    Sick.GenIStreamDotNet.dll は多くの場合 .NET Framework 向け（C++/CLI混在）。 → 新規プロジェクトを .NET 6/7 の Windows Forms で作ると不一致になりやすいです。

    Windows Forms App (.NET Framework) で作り直す（.NET Framework 4.7.2〜4.8 を推奨）

    既存が .NET Core/5+/6+ なら、4.8 の WinForms プロジェクトに変更して DLL を参照し直す

    ③ ネイティブ依存 DLL が見えるようにする

    Sick.GenIStreamDotNet.dll 本体だけでなく、同梱のネイティブ DLL 群（x64） がロードパスに必要です。 （例：genistream*.dll など）

    対処いずれか：

    サンプルが使っている 出力フォルダコピーの仕組みを真似する

    参照設定の Copy Local = True

    あるいは ポストビルドイベントで SICK SDK の bin\x64\ を $(TargetDir) にコピー

    または起動時に SetDllDirectory／PATH 追加でネイティブの場所を通す：

    // Program.Main の先頭で [System.Runtime.InteropServices.DllImport("kernel32.dll", SetLastError = true)] static extern bool SetDllDirectory(string lpPathName);

    static void Main() { // SICK の x64 ネイティブ DLL があるフォルダに置き換えてください SetDllDirectory(@"C:\SICK\StreamSDK\bin\x64"); // …通常の Application.Run へ }

    ④ .cti のパスはフルパスで

    相対 "SICKGigEVisionTL.cti" だと作業フォルダ次第で見つかりません。 サンプル同様の フルパスを渡してください：

    var discovery = CameraDiscovery.CreateFromProducerFile( @"C:\SICK\TL\SICKGigEVisionTL.cti" );

    （環境変数 GENICAM_GENTL64_PATH でディレクトリを通しておく方法でも可）

    ⑤ それでもダメなときの切り分け

    Environment.Is64BitProcess を確認（Trueであること）

    例外が BadImageFormat のまま → ビット数不一致が残存

    例外が DllNotFoundException に変わった → ネイティブ DLL のパス問題

    サンプルと 同じ参照 DLL を使っているか（誤って x86 版や別ディレクトリを参照していないか）

    // Program.Main の先頭など、CameraDiscovery を触る前に [System.Runtime.InteropServices.DllImport("kernel32.dll", SetLastError = true)] static extern bool SetDllDirectory(string lpPathName);

    static void AddDllPath(string path) { if (!System.IO.Directory.Exists(path)) return; // 1) DLL検索ディレクトリとして追加 SetDllDirectory(path); // 2) ついでに PATH にも追加（子プロセス等にも有効） var current = Environment.GetEnvironmentVariable("PATH") ?? ""; if (!current.Contains(path, StringComparison.OrdinalIgnoreCase)) Environment.SetEnvironmentVariable("PATH", current + ";" + path); }

    static void Main() { // ★あなたの環境に合わせて正しいフォルダを指定してください AddDllPath(@"C:\SICK\StreamSDK\bin\x64"); // GenIStream のネイティブDLL AddDllPath(@"C:\SICK\GigEVisionTL\bin\x64"); // SICK GigE Vision Producer のネイティブDLL // （サンプルが参照している実フォルダを確認して同じにするのが一番確実）
